How we decide

Rules of thumb

Global is for you

Only things you want in every session go in ~/.claude: how you like to work, tools you use everywhere. Everything global costs attention in every chat.

Projects are for the work

A skill, server or rule that only helps videos goes in AI-VIDEO-EDITING, and so on. Project setup travels with GitHub, so a new laptop gets it with one clone.

Knowledge lives in files

Claude doesn't remember chats. Lessons go in LESSONS.md, rules in CLAUDE.md, repeatable prompts become skills. Then they're pushed to GitHub.

Not everything good gets in

Each new resource gets a verdict: keep, where, or skip. Overlapping tools make Claude slower and less focused, not smarter.

How this page stays current

Claude re-scans your setup and republishes this same link. You can also ask any session: “update my Goldmine page”. The scanner and research log live in ~/.claude/goldmine/.
